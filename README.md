## Antes de publicar

- [ ] Trocar o número do WhatsApp `5583900000000` em `index.html` (aparece 2 vezes)
- [ ] Trocar o link `#` do botão "Conheça nossos produtos"
- [ ] Ajustar `SEU-USUARIO` e `NOME-DO-REPOSITORIO` na tag `og:image` (pré-visualização ao compartilhar)

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos para a raiz
2. Vá em **Settings → Pages**
3. Em **Source**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`
4. Salve. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
